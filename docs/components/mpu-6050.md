# GX5s Logger Board - MPU-6050 Motion Sensor

**Reference:** U1  
**Part marking:** `MPU-6050_C24112`  
**Function:** 6-axis inertial measurement unit: 3-axis accelerometer and 3-axis gyroscope  
**Schematic label:** APS (MPU-6050)  
**Schematic sheet:** 5/5  
**Source schematic:** `SCH_GX5s-v210620_2026-09-19.pdf`

## Key specifications

| Property | Specification |
|---|---|
| Sensor axes | 3-axis gyroscope + 3-axis accelerometer |
| Gyroscope full-scale ranges | ±250, ±500, ±1000, ±2000 °/s |
| Accelerometer full-scale ranges | ±2, ±4, ±8, ±16 g |
| ADC resolution | 16-bit for gyro and accelerometer outputs |
| Supply voltage, VDD | 2.375 V to 3.46 V |
| Logic supply, VLOGIC | 1.8 V ±5% or VDD |
| GX5s supply | 3.3 V for VDD and VLOGIC |
| Interface | I2C only for MPU-6050 |
| I2C speed | 100 kHz standard mode or 400 kHz fast mode |
| I2C address | `0x68` when AD0 is low; `0x69` when AD0 is high |
| Operating temperature | -40 °C to +105 °C device specification |
| Digital Motion Processor | Included |

## Pin mapping

| MPU-6050 pin | Function | GX5s connection |
|---:|---|---|
| 1 | CLKIN | GND; internal clock used |
| 2, 3, 4, 5 | NC | No functional connection shown |
| 6 | AUX_DA | No external connection shown |
| 7 | AUX_CL | No external connection shown |
| 8 | VLOGIC | `3V3` |
| 9 | AD0 | GND; selects I2C address `0x68` |
| 10 | REGOUT | C24, 100 nF |
| 11 | FSYNC | GND |
| 12 | INT | `APS-INT` to ESP32 |
| 13 | VDD | `3V3` |
| 14, 15, 16, 17 | NC | No functional connection shown |
| 18 | GND | GND |
| 19, 21, 22 | Reserved | No connection shown; do not use |
| 20 | CPOUT | C22, 10 nF |
| 23 | SCL | `I2C-SCL` to ESP32 GPIO27 |
| 24 | SDA | `I2C-SDA` to ESP32 GPIO14 |

## Local support components

| Reference | Value/function |
|---|---|
| C22 | 10 nF charge-pump capacitor at CPOUT |
| C24 | 100 nF regulator-output capacitor at REGOUT |
| C29 | 2.2 nF local support capacitor shown on the schematic |
| C38 | 100 nF local supply capacitor shown at the sensor |

## Firmware integration

- Use the shared I2C bus on `I2C-SDA` and `I2C-SCL`.
- Start with 7-bit address `0x68`; AD0 is shown tied to GND.
- Configure the `APS-INT` interrupt input according to the firmware wake strategy.
- Select the required accelerometer and gyroscope full-scale ranges during initialisation.
- Validate the device identity and power/voltage status before enabling motion processing.
- The auxiliary I2C pins are not routed to an external sensor in the supplied schematic.

## Verification items

- Confirm the exact physical MPU-6050 package and assembled part marking.
- Confirm C29 and C38 values and their exact PCB nets.
- Confirm the live I2C address is `0x68`.
- Confirm interrupt polarity and whether `APS-INT` is configured as latched or pulsed.
- Perform sensor-bias calibration on the assembled board.
